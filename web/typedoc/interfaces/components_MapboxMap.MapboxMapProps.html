    Interface MapboxMapProps

    Minimal, Mapbox-gl based map used in dashboard climate layer previews and other light-weight map contexts.

    The optional raster-related props are used by the public forecast drawer and dashboard climate previews to place a TiTiler-backed overlay above the base style without introducing a second map abstraction.
